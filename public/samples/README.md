# 匯入格式合成範例

本目錄只含 **TEST 合成資料，不能當成真實行情**。下載 JSON 後，可在管理員的「匯入資料」介面選擇資料包進行檢查；測試時使用獨立本機資料目錄，勿與正式行情混用。

| 格式 | 範例檔 | 預期結果 |
| --- | --- | --- |
| v1 | [import-valid.json](import-valid.json) | 檢查通過；含轉板、股票、ETF、指數、停牌及無成交 |
| v1 | [import-invalid.json](import-invalid.json) | 檢查失敗；示範缺列、重複及不合法價格 |
| v1 | [import-revision.json](import-revision.json) | 使用新批次編號的修訂範例 |
| v2 | [import-v2-valid.json](import-v2-valid.json) | 檢查通過；同時提供價格／量口徑、區段還原基準日、來源參照及無價依據 |

v2 範例保留普通交易時段無成交時的正數全日合計量（示意值 96），且原始／還原價格均為 null；停牌但成交量未知時明確使用 null。不要為了通過檢查把正量改為零或補上價格。

v2 範例的每個 `source_ref` 是以固定合成文字產生的 SHA-256，只示範欄位格式，沒有對應任何官方來源。真實資料必須提供自己的實際來源證據，不能沿用範例參照或只修改版本數字。

`rs-test.json` 是較大的 RS 運算合成測試包，同樣不是市場資料。小型格式範例只有六筆價格，不足以產生完整 RS 歷史圖表；通過結構檢查不表示完成來源驗收，也不會自動啟用行情。

完整規格：[v1](../../docs/資料匯入格式-v1.md)／[v2](../../docs/資料匯入格式-v2.md)。在 GitHub 檔案頁可使用「Download raw file」下載 JSON。
