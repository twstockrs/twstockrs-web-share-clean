# 來源行情匯入格式 v2

本版在 [v1 格式](資料匯入格式-v1.md) 上擴充，程式同時支援 v1 與 v2。v1 的證券身分、歷史市場／產業有效期間、完整開休市日曆、來源版本及每包 512 MiB 上限仍適用。不能只將舊包的版本數字改成 2。

可下載 [v2 合法合成範例](../public/samples/import-v2-valid.json)，並參考[範例說明](../public/samples/README.md)。範例標為 `dataset_kind: "test"`；所有價格、成交量、停牌情境及 `source_ref` 均為合成示範，不是官方來源或真實行情。範例涵蓋轉板、停牌時明確保留未知成交量 null，以及普通交易時段無成交但全日合計量為正數的情況。

## 欄位與成交語意

- 最外層使用 `version: 2`。
- manifest 新增 `price_scope: "regular_session"` 與 `volume_scope: "official_daily_aggregate"`：價格是普通交易時段，量是官方全日合計，可能包含零股，不能視為同一口徑。
- market_periods 每列新增 `adjustment_reference_date`，宣告個別市場區段還原基準日，允許明確的 null。有效期間仍採含起日、不含迄日。
- prices 每列新增 `source_ref`（64 位小寫 SHA-256 來源參照）與 `no_price_basis`。
- traded 的 `no_price_basis` 為 null，原始價與還原價均須為正數，股票／ETF 成交量須為正整數；指數成交量可為 null。
- no_trade 使用 `regular_session_no_trade`；suspended 使用 `official_suspension`。兩種狀態的原始價、還原價須為 null，原因必填。成交量保留官方全日原值，可為正數或零；官方停牌且來源量未知時可明確為 null。不得為了通過檢查把正量改成零，或把缺價補成有效價格。
- unavailable 仍不能保存為通過的行情批次。

所有來源對照與身分確認須在私人資料處完成。source_ref 只是參照，不能取代來源內容、版本與品質驗證。價格運算使用 IEEE-754 double；必要的原始十進位文字與還原明細保留在受保護的來源紀錄中。

## 運算快取與備份

原始匯入 JSON、驗證報告與版本不變；可重建的 `import_runtime`／`import_runtime_chunks` 保存壓縮運算副本，表頭與每塊雜湊組成 root，綁定來源版本。計算前逐塊檢查，不改價格、量、狀態或理由。

邏輯匯入資料庫仍為 user_version=2，另有兩張快取表。完整備份同時辨識舊結構與本版結構；v1 舊備份可還原，含 v2 與新快取的備份須使用本版或更新程式。不得刪除正式資料庫快取表或降級包格式來遷就舊程式。

完整備份在一致快照上逐包重驗原文與快取，不一次載入全部來源 JSON。已安裝主機將檢查與封裝交給背景工作，下載採串流；網頁直接下載與自動備份仍未加密，須存放於私人位置。

## 完整歷史檢視

Pro 可檢視啟用版本提供的全部已發布日端點與已完成週端點；傳輸上限為每頻率 3661 個端點，足以涵蓋四年。年份／月份與日、週日期選擇只接受合法端點。休市、未完成週及版本外日期不能當成有效觀測。

這是 History（可檢視日期）擴充；日頻 Period／Trail 上限仍為 240，週頻仍為 52，股票容量仍為 100。Anonymous／Free 的權限維持既有規則。早期資料不足、缺價、停牌與轉板不會補點。

Raw／Adjusted 的市場基準依來源版本中明確宣告的原始價格指數／總報酬指數取值，不能推定與個股還原演算法完全相同。顯示名稱為來源快照，不代表完整歷史名稱或當時資訊可得性。

## 資料邊界

儲存庫與程式交付包只含程式及明確標為 TEST 的合成範例；不含真實行情、帳號、密碼、資料庫、私人來源對照或備份。資料與備份放在外部受保護目錄，測試使用副本。本機驗收不代表公開部署。
